1. 작품 소개에 쓸 내용

고양이가 양쪽 앞발로 도자기를 밀어 떨어뜨리는 3D 물리 액션 로그라이트. 집주인이 돌아오기 전 약 3분 동안 도자기를 깨며 고득점을 노립니다. 파괴 등급과 콤보로 점수·경험치를 얻고, 레벨업 카드로 앞발과 연쇄 파괴 능력을 강화합니다.

기획 의도: 고양이가 물건을 떨어뜨리는 익숙한 행동을 물리 충돌과 연쇄 파괴의 손맛으로 확장했습니다. 1차 과제에서 제작한 고양이·식탁·도자기를 실제로 조작하고 파괴할 수 있는 게임으로 연결하는 데 초점을 두었습니다.

종료 규칙: 적을 처치하거나 승리 지점에 도달하는 방식이 아니라, 제한 시간이 끝나면 집주인이 돌아오고 최종 기록을 확인하는 점수 경쟁형입니다. 별도의 승리 판정이 있다고 설명하지 않습니다.

조작: A/D 또는 방향키로 이동 · 마우스 좌/우 버튼을 눌렀다 떼어 양손 Swipe · 1/2/3 또는 카드 클릭으로 강화 선택 · ESC 일시정지 · 결과 화면에서 R 재시작. 카드 클릭은 코드 반영 상태이며 최종 수동 검증이 필요합니다.

현재 플레이 화면 근거: Captures/screenshot-20261021-171610.png. 최종 포트폴리오 대표 이미지는 제출 빌드에서 다시 촬영하는 것을 권장합니다.

4. 오류 해결 사례에 쓸 수 있는 설명

대표 사례 · 카드 선택 중 카메라가 계속 밀리는 문제

증상: 도자기를 강하게 파괴한 뒤 카드 화면이 나타나면 카메라가 한쪽으로 계속 이동했습니다.

분석: 입력·고양이 위치·카메라 위치를 기록했습니다. 고양이는 정지해 있었지만 카메라만 이동했으므로, 단순한 키 입력 문제라는 초기 가설을 배제했습니다.

원인과 수정: 이전 프레임의 흔들림이 더해진 카메라 위치를 다음 추적의 기준으로 재사용했습니다. 정지 중에는 추적과 흔들림 시간이 진행되지 않아 오프셋이 누적됐습니다. 흔들림과 무관한 추적 좌표 followX를 분리하고, 정지 중에는 흔들림을 적용하지 않도록 수정했습니다.

검증 근거: 개발 기록에는 흔들림 0.08m, 300프레임 후에도 기준 X좌표가 유지된 결과가 있습니다. 제출 버전에서도 강한 파괴 직후 카드 선택 상황을 다시 확인합니다.

보조 사례 · 배경보다 플레이가 중요하다는 구도 수정

일체형 주방 에셋을 화면에 맞추며 비율을 누르고 낙하 바닥을 가렸습니다. 가구를 멀리 물리는 것만으로는 배경이 사라졌고, 카메라를 넓히자 고양이와 도자기가 작아졌습니다. 최종적으로 가까운 카메라를 복원하고 조리대·벽을 가장자리에서 잘려 보이게 연결했습니다. 실패한 결과도 숨기지 않고, 사용자 피드백이 설계 판단을 어떻게 바꿨는지 보여주는 사례로 활용할 수 있습니다.

5. 제출 전 진행 순서

  1. 최신 버전 한 판 검증: 실제 키·마우스로 시작 → 이동·양손 Swipe → 파괴·콤보 → 카드 클릭·숫자 선택 → 세 진행 구간 → 시간 종료 → 결과 → R 재시작. 카드 선택 후 입력과 카메라가 정상인지 확인합니다.
  2. 사운드 청감 확인: 재생 이벤트 연결 검사는 통과했으나 자동 출력 파형 검사에서 신호가 0으로 나왔습니다. 실제 소리가 들리는지, 파괴음이 BGM에 묻히지 않는지 직접 확인해야 합니다. 스크립트 재컴파일 후 빠른 Play 설정에서 초기화 오류가 있었고, 씬 재로드 후 이벤트 검사는 통과했습니다.
  3. Windows PC 빌드 생성·실행: 출력된 게임을 에디터 밖에서 실행하고 입력·한글·화면비·종료·재시작·사운드를 점검합니다. 현재 SampleScene도 빌드 목록에 있으므로 제출 대상 씬 구성을 확인합니다. 이 정리 작업에서는 빌드 설정을 바꾸지 않았습니다.
  4. 영상 1~2분 녹화: 일반 플레이, 연쇄 파괴·콤보, 카드 선택, 후반 도자기, 결과 화면을 편집으로 연결합니다. 약 3분짜리 게임 전체를 배속 없이 담을 필요는 없습니다. 편집된 시연임을 밝혀주세요.
  5. PDF 제작: 위 구성으로 실제 화면·주요 코드·AI 요청·오류 해결을 배치하고 02_Unity_정우영.pdf로 저장합니다. 첫 장 GitHub 링크와 클릭 가능 여부를 확인합니다.
  6. 전달 점검: 빌드·영상·프로젝트는 저장소 또는 02_정우영 폴더로 전달합니다. 원격 저장소 URL 등록은 확인했지만 최신 수정의 업로드는 별도 확인이 필요합니다. commit·push는 이 작업에 포함하지 않았습니다.

6. 제출 형식과 출처

필수: 02_Unity_정우영.pdf 1부 + 첫 장 GitHub 링크 · PC 실행 빌드 · 플레이 영상 1~2분 · 평가지 대표 이미지 칸에 대표 화면을 붙여 출력.

에셋 구분: 고양이·식탁·도자기는 1차 과제의 바르코 생성·Blender 정리 결과입니다. 현재 주방 구조에는 단순 도형으로 만든 요소가 있고, 화분과 바닥 텍스처는 이번 바르코 생성물입니다. 비활성 일체형 카운터를 최종 사용 에셋처럼 소개하지 않습니다.

사운드: Kenney Impact Sounds·Interface Sounds·Music Jingles, Fupi의 Short Plingy Loop는 CC0입니다. 앞발 바람 소리는 코드 합성입니다. 바르코 생성 사운드가 아닙니다. 원문 라이선스는 Assets/Audio/에 있습니다.

글꼴: Jua, SIL OFL 1.1. Assets/Fonts/Jua/OFL.txt를 배포물에도 보존합니다.
