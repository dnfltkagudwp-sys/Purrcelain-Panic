파손 등급 · 콤보 · 경험치

파손 등급: 세게, 멀리 깰수록 보상

판정 점수 = 바닥 충돌 속도 점수 × 0.65 + 비거리 점수 × 0.35
등급판정 점수점수경험치연출
CRACK0.35 미만1001작은 팝업
SMASH0.35 ~ 0.701602흔들림 0.04 m, 불꽃 6
PURRFECT0.70 이상2503흔들림 0.08 m, 불꽃 12, 고리

Fragile은 0.60부터 PURRFECT · Collector는 점수 ×2, 경험치 +2

Normal(질량 1.0) · Fragile Batch(0.75) · Collector’s China(1.25)

콤보

  • 마지막 파괴 후 2초 안에 다음 파괴 → 콤보 유지
  • 배율 = 1 + (콤보 − 1) × 0.25, 최대 ×3
  • 10콤보마다 유지 시간 −0.3초 (최소 1.1초) → 긴 콤보일수록 어려움

경험치와 레벨업

  • 필요 경험치 = 4 + 5 × (현재 레벨 − 1)
  • 레벨업하면 게임이 멈추고 카드 3장 중 1장 선택
  • 능력 슬롯 6칸, 능력마다 최대 Lv 5 (뱀파이어 서바이버식)
  • 슬롯이 차면 보유 능력 강화만, 고를 카드가 없으면 500점
보상 구조 원문
“더 재미있으려면 멀리 밀렸을 때, 더 세게 밀었을 때 뭔가 있어야 할 것 같아. 더 많은 조각으로 깨진다든지, 그러면 점수나 경험치를 더 많이 얻는다든지.”

① VARCO 컨셉
둥근 카툰풍 수납장·소품 생성 → 3D 모델로 변환

배경은 보이지만 고양이와 도자기가 작아짐
③ 최종
가까운 카메라 유지, 조리대·벽이 가장자리에서 잘려 보임
피드백 원문
“비율도 문제고, 도자기는 어디가서 깨지냐?”
“배경을 보여주기 위해 카메라를 당겨서 정작 중요한 고양이랑 도자기 깨지는게 잘 안보여. 에셋이 잘려서 보여도 돼. 중요한건 분위기를 잘 만들어내는거야”

// BreakableVase.cs — 식탁 위에서 다른 도자기와 부딪혔을 때
void TryTransfer(BreakableVase other)
{
    // 앞발에 맞지 않았거나, 이미 전달했거나, 같은 휘두르기면 전달하지 않음
    if (SwipeId == 0 || HasTransferred || other.broken || other.SwipeId == SwipeId) return;
    float speed = lastVelocity.magnitude;
    if (speed < tuning.chainMinSpeed) return;   // 너무 느리면 연쇄 없음
    // 방향: 두 중심을 잇는 방향 70% + 친 쪽 진행 방향 30%
    Vector3 dir = (toOther * tuning.chainCenterWeight + travel * (1f - tuning.chainCenterWeight)).normalized;
    // 전달률 60% (도미노 효과로 최대 95%) → 100% → 60% → 36% …
    other.ReceiveChain(SwipeId, ChainStep + 1, dir * speed * ChainTransferRate);
    body.linearVelocity = lastVelocity * tuning.chainCarrierKeep;   // 친 쪽은 감속
    HasTransferred = true;
}
