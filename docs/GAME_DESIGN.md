# Purrcelain Panic 초기 구현 기획서

> 본문 수치와 부록 B 튜닝표가 다를 때는 **부록 B가 우선**한다. 부록 A는 구현 전 검토에서 바뀐 사항이다.

## 1 게임 개요

Purrcelain Panic은 식탁 뒤에 선 이족보행 고양이가 양쪽 앞발로 도자기를 휘둘러 떨어뜨리는 3D 물리 액션 로그라이트 게임이다.

도자기를 강하고 멀리 날릴수록 높은 파괴 등급과 점수, 경험치를 얻는다. 경험치가 쌓이면 카드 3장 중 하나를 선택해 앞발, 콤보, 물리 충돌, 도자기 생성 방식을 강화한다.

한 게임은 약 3분 동안 진행된다. 시간이 흐를수록 도자기 생성 속도와 종류, 배치가 어려워진다.

## 2 핵심 게임 흐름

```text
도자기 생성
    ↓
고양이 좌우 이동
    ↓
왼손 또는 오른손 충전
    ↓
앞발 휘두르기
    ↓
도자기 충돌과 연쇄 이동
    ↓
식탁에서 낙하
    ↓
파괴 등급 판정
    ↓
점수와 경험치 획득
    ↓
능력 카드 선택과 강화
```

## 3 게임 종료 조건

게임 시작 시 `Owner ETA`가 약 180초 주어진다.

- Owner ETA는 게임 전체에 걸쳐 계속 감소한다.
- 강한 파괴로 시간이 추가 감소하지 않는다.
- 시간 증가, 부활, 경험치 증가 카드는 사용하지 않는다.
- Owner ETA가 0이 되면 집주인이 돌아오며 게임이 종료된다.
- 최종 점수, 최고 콤보, PURRFECT 횟수를 결과 화면에 표시한다.

강하고 빠르게 깨는 행동은 항상 좋은 결과로 이어져야 한다.

## 4 스테이지 진행

한 게임은 시간에 따라 세 스테이지로 나뉜다. 씬을 다시 불러오지 않고 `StageDirector`가 생성 규칙과 사용 가능한 식탁 구간을 변경한다.

### 스테이지 1

- 진행 시간: 0~60초
- 일반 도자기만 등장
- 단독 생성과 2개 나란히 생성
- 느린 생성 속도
- 기본 물리와 양손 조작 학습

### 스테이지 2

- 진행 시간: 60~120초
- 추가 식탁 구간과 생성 지점 해금
- Fragile Batch 등장
- 앞뒤 직선 배열 추가
- 생성 속도 증가
- 두세 개 도자기의 충돌 유도

### 스테이지 3

- 진행 시간: 120~180초
- 전체 식탁 구간 사용
- Fragile Batch와 Collector’s China 등장
- 2~3개 묶음과 군집 배열 추가
- 가장 빠른 생성 속도
- 무거운 도자기와 일반 도자기가 섞여 등장

## 5 카메라

카메라는 고양이 머리 바로 뒤쪽과 위쪽에 배치한다.

- 고양이 머리와 귀는 화면 아래 중앙에 표시
- 왼손과 오른손이 모두 같은 비중으로 보이는 대칭 구도
- 식탁 상판은 화면 중앙
- 식탁의 먼 쪽 끝과 파손 바닥은 화면 위쪽
- 고양이 하체는 화면 밖으로 제외
- 시야각은 약 50~55도
- 아래로 약 40~50도 내려다봄
- 고양이의 X축 이동을 부드럽게 추적

화면에서 도자기가 밀리고, 다른 도자기와 충돌하고, 식탁에서 떨어져 깨지는 과정이 모두 보여야 한다.

## 6 조작법

- A 또는 왼쪽 방향키: 왼쪽 이동
- D 또는 오른쪽 방향키: 오른쪽 이동
- 마우스 왼쪽 버튼: 왼손 충전 및 Swipe
- 마우스 오른쪽 버튼: 오른손 충전 및 Swipe
- 숫자 1, 2, 3: 능력 카드 선택
- ESC: 일시정지

왼손과 오른손은 각각 별도의 충전량과 재사용 대기시간을 가진다.

## 7 고양이 이동

고양이는 식탁을 따라 X축으로만 이동한다.

- 하체가 보이지 않으므로 걷기 애니메이션은 사용하지 않는다.
- 이동 중에도 상체의 기본 Idle을 유지한다.
- 스테이지가 올라가 식탁 구간이 늘어나면 이동 가능 범위도 넓어진다.
- 이동은 Rigidbody보다 직접 위치 이동 방식을 사용한다.

## 8 앞발 Swipe

고양이는 손바닥으로 정면을 밀지 않고 앞발을 곡선으로 휘둘러 도자기를 쓸어낸다.

### 애니메이션

- `Idle_Lean`
- `Swipe_L`
- `Swipe_R`

각 Swipe는 다음 과정으로 구성한다.

1. 앞발을 몸 안쪽이나 뒤쪽으로 당긴다.
2. 어깨와 상체를 약간 회전한다.
3. 앞발을 바깥쪽과 전방을 향해 휘두른다.
4. 손목이 도자기를 쓸어내듯 통과한다.
5. 기본 자세로 돌아온다.

### 방향

- 왼손은 전방과 왼쪽을 향해 휘두른다.
- 오른손은 전방과 오른쪽을 향해 휘두른다.
- 기본 방향 비율은 전방 70%, 좌우 30% 정도로 시작한다.
- 약간의 위쪽 힘을 추가해 도자기가 자연스럽게 들리고 회전하게 한다.

## 9 충전 시스템

마우스 버튼을 누르고 있는 동안 해당 손의 힘을 모은다.

### 초기 설정

- 최소 밀기 힘: 4
- 최대 밀기 힘: 12
- 최대 충전시간: 1초
- 손별 재사용 대기시간: 0.6초

```text
Charge01 = 누른 시간 ÷ 최대 충전시간
SwipeForce = 최소 힘과 최대 힘 사이를 Charge01로 보간
```

충전량은 힘의 크기에만 영향을 준다. 애니메이션은 같은 Swipe를 사용한다.

## 10 Swipe 충돌 판정

손에 실제 물리 Collider를 붙이는 대신 손이 이동한 경로를 따라 충돌을 검사한다.

1. Swipe의 타격 구간을 시작한다.
2. 이전 프레임의 손 위치를 저장한다.
3. 현재 손 위치까지 Sphere Cast를 실행한다.
4. 처음 닿은 도자기에 힘을 적용한다.
5. 같은 Swipe에서 같은 도자기를 두 번 타격하지 않는다.
6. 타격 구간이 끝나면 검사를 종료한다.

도자기에 적용하는 방향은 다음처럼 계산한다.

```text
손의 실제 이동 방향 60%
고양이의 전방 방향 40%
```

힘은 도자기의 중심이 아니라 손이 닿은 위치에 `AddForceAtPosition`으로 적용한다. 도자기는 밀리면서 회전하게 된다.

## 11 도자기 생성

도자기는 완전한 무작위 좌표가 아니라 식탁 위에 배치된 SpawnPoint 중 비어 있는 지점에 생성한다.

### 기본 생성 패턴

- 단독 생성
- 좌우로 나란히 2개 생성
- 앞뒤 직선 배열
- 가까운 군집 배열

SpawnPoint는 식탁의 X축과 Z축 방향으로 격자 형태로 배치한다.

생성기는 다음 정보를 관리한다.

- 현재 스테이지
- 생성 간격
- 비어 있는 SpawnPoint
- 식탁 위 도자기 수
- 생성 패턴 확률
- 도자기 종류 확률
- 현재 활성화된 식탁 구간

식탁이 가득 차면 새로운 생성은 잠시 중단된다. 즉시 게임오버가 되지는 않지만 점수와 경험치를 얻을 기회가 줄어든다.

## 12 도자기 종류

### Normal Vase

기본 도자기다.

- Mass: 1.0
- 기본 파편 수와 점수 사용
- 모든 스테이지에서 등장

### Fragile Batch

스테이지 2부터 등장하는 가벼운 도자기다.

- 일반 도자기보다 가벼움
- 초기 Mass 권장값: 0.75
- 멀리 날아가기 쉬움
- PURRFECT 판정이 쉬움
- 작은 파편과 부스러기 효과가 많음
- 일반 도자기와 시각적으로 구분되는 얇고 밝은 머티리얼 사용
- 카드가 아니라 스테이지 진행에 따라 자동 등장

### Collector’s China

스테이지 3부터 등장하는 무겁고 가치가 높은 특수 도자기다.

- 일반 도자기보다 약 25% 무거움
- 초기 Mass 권장값: 1.25
- 밀고 연쇄시키기 어려움
- 기본 점수 배율 증가
- 경험치 보너스 지급
- 금색 장식이나 고급스러운 머티리얼로 구분
- 카드가 아니라 스테이지 진행에 따라 자동 등장

## 13 도자기 충돌과 힘 전달

도자기가 다른 도자기와 충돌할 때 힘은 점차 약해진다.

기본 힘 전달률은 약 60%로 시작한다.

```text
첫 번째 도자기  100%
두 번째 도자기   60%
세 번째 도자기   36%
네 번째 도자기   22%
```

각 도자기는 다음 정보를 기록한다.

- 현재 Swipe 식별 번호
- 현재 연쇄 단계
- 전달받은 힘
- 같은 Swipe에서 충돌 효과를 전달했는지 여부

같은 Swipe에서 하나의 도자기는 연쇄 힘을 한 번만 전달한다. 이 규칙으로 무한 충돌과 중복 점수를 방지한다.

## 14 파괴 처리

도자기가 식탁의 먼 쪽으로 떨어져 바닥에 처음 충돌하면 파괴된다.

1. 충돌 속도를 측정한다.
2. 식탁을 벗어난 위치부터 충돌 위치까지의 거리를 측정한다.
3. 파괴 품질을 계산한다.
4. 파괴 등급을 결정한다.
5. 점수와 경험치를 지급한다.
6. 온전한 도자기를 비활성화한다.
7. 같은 위치에 파편 프리팹을 생성한다.
8. 파편에 충돌 세기에 따른 힘을 적용한다.
9. 파편을 약 4초 후 제거한다.

실시간 메시 절단은 사용하지 않는다.

## 15 파괴 등급

```text
SpeedScore = 충돌 속도를 0에서 1로 정규화
DistanceScore = 비행 거리를 0에서 1로 정규화

ImpactQuality =
SpeedScore × 0.65
+ DistanceScore × 0.35
```

| 등급 | 기본 점수 | 경험치 | 연출 |
|---|---:|---:|---|
| CRACK | 100 | 1 | 기본 파편 |
| SMASH | 160 | 2 | 강한 파편과 먼지 |
| PURRFECT | 250 | 3 | 추가 부스러기와 강한 연출 |

강한 파괴에 시간 페널티는 없다.

## 16 콤보

도자기를 연속으로 깨뜨리면 콤보가 증가한다.

- 기본 콤보 유지시간: 2초
- 도자기 파괴당 콤보 1 증가
- 콤보 시간이 끝나면 초기화
- 최대 점수 배율: 3배

```text
콤보 배율 = 1 + 콤보 단계 × 0.25
최종 점수 = 기본 점수 × 콤보 배율
```

## 17 레벨업과 카드 선택

파괴 등급에 따라 경험치를 획득한다.

경험치 요구량은 레벨이 올라갈수록 증가한다.

레벨업하면 게임과 물리를 일시정지하고 카드 3장을 표시한다.

### 카드 규칙

- 액티브 능력 없음
- 모든 카드는 패시브 또는 조건부 자동 발동
- 능력 슬롯은 최대 6개
- 각 능력은 최대 레벨 5
- 보유하지 않은 카드를 선택하면 새 능력 획득
- 이미 보유한 카드를 선택하면 해당 능력 레벨 상승
- 슬롯이 가득 차면 보유 능력의 강화 카드만 등장
- 최대 레벨 능력은 카드 목록에서 제외
- 시간 증가, 부활, XP 증가 카드는 등장하지 않음

## 18 능력 목록

### Iron Paw

최초 Swipe 힘을 증가시킨다.

- 레벨당 밀기 힘 약 12% 증가
- 최대 레벨에서 총 60% 증가

### Domino Effect

도자기끼리 충돌할 때 손실되는 힘을 줄인다.

| 상태 | 힘 전달률 |
|---|---:|
| 기본 | 60% |
| Lv 1 | 67% |
| Lv 2 | 74% |
| Lv 3 | 81% |
| Lv 4 | 88% |
| Lv 5 | 95% |

### Quick Swipe

각 손의 Swipe 후 복귀시간을 줄인다.

- 레벨당 재사용 대기시간 8% 감소
- 최대 40% 감소

### Wide Arc

손의 휘두르기 궤적과 충돌 판정을 넓힌다.

- 레벨당 Sphere Cast 반경 약 8% 증가
- 여러 도자기를 동시에 맞힐 가능성 증가

### Alternating Paws

왼손과 오른손을 번갈아 적중시키면 다음 Swipe가 강해진다.

- 레벨당 교대 Swipe 힘 보너스 증가
- 같은 손을 연속 사용하면 보너스 초기화

### Combo Keeper

콤보 유지시간을 늘린다.

- 레벨당 유지시간 0.25초 증가
- 최대 1.25초 증가

### Domino Display

앞뒤로 정렬된 도자기 배열의 생성 확률을 높인다.

- 낮은 레벨에서는 2개 직선 배열 증가
- 높은 레벨에서는 3개 직선 배열 등장
- Domino Effect와 조합하기 좋음

### Full Set

한 번에 여러 도자기가 생성될 확률을 높인다.

- 점수와 XP 획득 기회 증가
- 파괴력이 부족하면 식탁이 빠르게 가득 차는 위험 존재
- 레벨이 올라갈수록 추가 생성 확률 증가

### Packed Display

도자기가 서로 가까운 SpawnPoint에 생성될 확률을 높인다.

- 도자기끼리 충돌하기 쉬워짐
- Wide Arc와 Domino Effect에 유리
- 파괴력이 부족하면 식탁이 막힐 가능성 증가

- Quick Swipe

### 균형 빌드

- Iron Paw
- Quick Swipe
- Domino Effect
- Alternating Paws
- Domino Display
- Combo Keeper

최초 힘과 연쇄 전달, 양손 속도를 고르게 강화한다.

## 20 주요 Unity 구성

### GameManager

- 게임 상태 관리
- Owner ETA 관리
- 게임 시작과 종료
- 일시정지와 결과 화면

### StageDirector
